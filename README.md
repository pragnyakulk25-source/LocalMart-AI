# LocaMart AI - Frontend

This ZIP package contains the complete standalone frontend for **LocaMart AI** (Hyperlocal E-Commerce Marketplace).

## Folder Structure
- `index.html` - Main HTML UI containing Buyer Portal and Seller Dashboard
- `app.js` - Complete application logic, API integrations, state management, and DOM manipulation
- `styles.css` - Stylesheet accompanying Tailwind CSS framework
- `README.md` - Setup instructions

## How to Run
1. Ensure your backend (`main.py`) is running at `http://127.0.0.1:8000`.
2. Open `index.html` in any modern browser (or use VS Code Live Server).
3. Test both the **Buyer Portal** and **Seller Dashboard**.
